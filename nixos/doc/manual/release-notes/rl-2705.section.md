## Backward Incompatibilities {#sec-release-27.05-incompatibilities}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- The `boot.loader.refind` module and the `refind` package have been removed because upstream rEFInd was unmaintained.

- `xdg.directories.enable` now defaults to `true` on `system.stateVersion >= 27.05`, which will cause `$XDG_CACHE_HOME`, `$XDG_CONFIG_HOME`, `$XDG_DATA_HOME`, and `$XDG_STATE_HOME` environment variables to be set to the values that should be used as a fallback if the variables are not set, as per [XDG Base Directory specification](https://specifications.freedesktop.org/basedir-spec/latest/).
  Theoretically, this should have no effect on compliant applications, but some applications only comply when they see those variables set, and otherwise just spam into the `$HOME` directory.
  This is wrong, but, hopefully, those applications at least know to *not* ignore their old files/directories in `$HOME` if those already exist.
  Otherwise, some breakage is going to happen.

- [](#opt-services.mealie.settings) has a proper type now:
  - Booleans are coerced to `"true"` and `"false"` instead of `"1"` and `""`.
  - Values other than booleans, ints, strings, paths or packages will be rejected.
  - `null` values now unset the value instead of producing an empty string.
