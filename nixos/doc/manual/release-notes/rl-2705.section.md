## Other Notable Changes {#sec-release-27.05-notable-changes}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `limine-install-ng`, a Rust rewrite of the Limine bootloader installer, is available for testing. It removes Python from the installer closure and can be enabled with {option}`boot.loader.limine.enableNg`. The Python installer is deprecated and is planned to be replaced by `limine-install-ng` in a future release, so please report any issues.
