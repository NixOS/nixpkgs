## New Modules {#sec-release-27.05-new-modules}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- [steve](https://gitweb.gentoo.org/proj/steve.git/), a system-wide GNU Make-compatible jobserver, is available as [services.steve](#opt-services.steve.enable). It regulates interactive and Nix builds on loaded machines according to various policies (memory pressure, loadavg pressure).

## Backward Incompatibilities {#sec-release-27.05-incompatibilities}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- The `boot.loader.refind` module and the `refind` package have been removed because upstream rEFInd was unmaintained.

- [](#opt-services.mealie.settings) has a proper type now:
  - Booleans are coerced to `"true"` and `"false"` instead of `"1"` and `""`.
  - Values other than booleans, ints, strings, paths or packages will be rejected.
  - `null` values now unset the value instead of producing an empty string.

## Other Notable Changes {#sec-release-27.05-notable-changes}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `limine-install-ng`, a Rust rewrite of the Limine bootloader installer, is available for testing. It removes Python from the installer closure and can be enabled with {option}`boot.loader.limine.enableNg`. Unlike the Python installer, it fails the installation when `limine bios-install`, `limine enroll-config` or `sbctl` fail instead of ignoring the error. The Python installer is deprecated and is planned to be replaced by `limine-install-ng` in a future release, so please report any issues.
