# Fluxer {#module-services-fluxer}

Fluxer is a self-hostable, free, and open-source chat and VoIP platform.

## Getting Started {#module-services-fluxer-getting-started}

A minimal setup can be achieved as follows:

```nix
{
  services.fluxer = {
    enable = true;
    aux = {
      nats.enable = true;
      pgsql.enable = true;
      valkey.enable = true;
      meilisearch.enable = true;
      seaweedfs.enable = true;
      nginx.enable = true; # or alternatively, caddy.enable = true
    };
    settings = {
      domain = "fluxer.example.com";
      vapid.email = "admin@fluxer.example.com";
      nats = {
        auth_token.file = "/path/to/secret";
        auth_token_bcrypt = "some-plaintext-hash";
      };
    };
  };
}
```

The nats auth token and corresponding hash can be generated by running `nix-shell -p natscli --run 'nats server passwd --generate'`

## Configuration {#module-services-fluxer-configuration}

The attributes under `settings` are turned into environment variables by uppercasing them, concatenating them with `_` and prefixing them with `FLUXER_`. For example, the configuration above would be transformed into the following set of environment variables:

```env
FLUXER_DOMAIN=fluxer.example.com
FLUXER_VAPID_EMAIL=admin@fluxer.example.com
FLUXER_NATS_AUTH_TOKEN_FILE=/path/to/secret
FLUXER_NATS_AUTH_TOKEN_BCRYPT=some-plaintext-hash
```

Attributes ending in `.file` are passed through systemd's `LoadCredential` mechanism. You do not need to ensure that the services have read permission to the files.

A full reference for configuration options can be found in the [official Fluxer documentation](https://docs.fluxer.com/operator/environment/)

## Secrets {#module-services-fluxer-secrets}

Fluxer needs a large number of configured secrets. As much as possible, the module generates secrets for you (refer to `fluxer-pregenerate-secrets.service` for details). Nats requires the hashed auth token to be passed directly, it therefore needs to be set manually. All other secrets can be manually overriden if you require more control over them.

Most of the secrets accept any random string. The following secrets require special attention:

- The web-push VAPID keys can be generated with `nix-shell -p nodejs --run 'npx web-push generate-vapid-keys'`.
- The media upload and attachment secrets need to be base64-encoded and at least 32 bytes long. Use `nix-shell -p openssl --run 'openssl rand -base64 32'`.
- The nats auth token needs to be bcrypt hash. A random token and the corresponding hash can be generated with `nix-shell -p natscli --run 'nats server passwd --generate'`.
- Livekit API keys can be generated with `nix-shell -p livekit --run 'livekit-server generate-keys'`. The first line is an identifier and the second line the corresponding secret.

## Distributed Setup {#module-services-fluxer-distributed-setup}

Fluxer is composed from multiple services and all of the services can theoretically run on different machines. To facilitate this, the subservices can be individually enabled or disabled and have their own settings (with defaults taken from `config.services.fluxer.settings`). Additionally, you will want to

- manually configure all shared secrets
- Configure internal (and potentially public) service endpoints.

The default public endpoints are:
```nix
{
  services.fluxer.settings = {
    api.endpoint = "https://fluxer.example.com/api";
    api.client_endpoint = "https://fluxer.example.com/api";
    app.endpoint = "https://fluxer.example.com/";
    gateway.endpoint = "wss://fluxer.example.com/gateway";
    media.endpoint = "https://fluxer.example.com/media";
    media_proxy.upload_relay.endpoint = "https://fluxer.example.com/media";
    admin.endpoint = "https://fluxer.example.com/admin";
    marketing.endpoint = "https://fluxer.example.com/marketing";
    invite.endpoint = "https://fluxer.example.com/invite";
    gift.endpoint = "https://fluxer.example.com/gift";
  };
}
```

::: {.warning}
In the default setup, fluxer serves static assets via the app-proxy. If you want to serve them differently, you can set `static_cdn.endpoint`. If not, leave this option unset or you will break the web app.
:::

The default internal endpoints are:
```nix
{
  services.fluxer.settings.internal = {
    api_endpoint = "http://127.0.0.1:10000";
    admin_endpoint = "http://127.0.0.1:10001";
    gateway_endpoint = "http://127.0.0.1:10002";
    media_proxy_endpoint = "http://127.0.0.1:10003";
    app_proxy_endpoint = "http://127.0.0.1:10004";
    livekit_endpoint = "http://127.0.0.1:7880";
  };
}
```
