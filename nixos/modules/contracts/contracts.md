# Contracts {#module-contracts}

This module adds the options [](#opt-contractTypes) and [](#opt-contracts) to NixOS.
It adds each contract type in `lib.contracts` to [](#opt-contractTypes).
With [](#opt-contracts), consumers send requests and providers send responses, so that consumers do not depend on one specific provider.

For more information, refer to the [Contracts](#contracts) chapter in the development part of the manual.
