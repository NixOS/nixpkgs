# Caelestia Shell {#module-programs-caelestia-shell}

[Caelestia Shell](https://github.com/caelestia-dots/shell) is a fluid, morphing desktop shell for Wayland, built with [Quickshell](https://quickshell.outfoxxed.me) and designed for the [Hyprland](https://hypr.land) window manager.

## Basic usage {#module-programs-caelestia-shell-basic-usage}

```nix
{
  programs.caelestia-shell = {
    enable = true;
    systemd.enable = true;
  };
}
```

The module installs Caelestia Shell and starts it from a systemd user service.
It also enables the recommended services and integrations: Hyprland, NetworkManager, Bluetooth, I2C, Power Profiles Daemon, GeoClue2, and GPU Screen Recorder.
To manage these services yourself, set [`programs.caelestia-shell.recommendedServices.enable`](#opt-programs.caelestia-shell.recommendedServices.enable) to `false`.

## Starting the shell {#module-programs-caelestia-shell-starting}

Enable [`programs.caelestia-shell.systemd.enable`](#opt-programs.caelestia-shell.systemd.enable) to start Caelestia Shell from a systemd user service.
The service starts when the target configured with [`programs.caelestia-shell.systemd.target`](#opt-programs.caelestia-shell.systemd.target) is reached.
With the default UWSM-based Hyprland setup, the target is `graphical-session.target`.

::: {.note}
If your Hyprland configuration already starts the shell, for example when using the [Caelestia dotfiles](https://github.com/caelestia-dots/caelestia), leave `programs.caelestia-shell.systemd.enable` disabled to avoid starting it twice.
:::

## Theming {#module-programs-caelestia-shell-theming}

The module installs and configures the Bibata-Caelestia cursor and Papirus icon themes by default.
Disable [`programs.caelestia-shell.cursor.enable`](#opt-programs.caelestia-shell.cursor.enable) or [`programs.caelestia-shell.icons.enable`](#opt-programs.caelestia-shell.icons.enable) to use your own themes.

The module enables the `qtengine` Qt platform theme by default, so Qt applications follow the colours generated by [`caelestia-cli`](https://github.com/caelestia-dots/cli).
