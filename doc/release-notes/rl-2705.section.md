# Nixpkgs 27.05 (2027.05/??) {#sec-nixpkgs-release-27.05}

## Highlights {#sec-nixpkgs-release-27.05-highlights}
<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- Node.js latest version has been updated from 26 to 27.
  This introduces some breaking changes; refer to the [Node.js 27 changelog](https://github.com/nodejs/node/blob/main/doc/changelogs/CHANGELOG_V27.md) for details.
- Node.js default version has been updated from 24 LTS to 26 LTS.
  This introduces some breaking changes; refer to the [Node.js 26 changelog](https://github.com/nodejs/node/blob/main/doc/changelogs/CHANGELOG_V26.md) for details.
  Node.js 26 no longer ships Corepack, so `nodejs` no longer provides a `corepack` executable; use the standalone `corepack` package instead.

## Backward Incompatibilities {#sec-nixpkgs-release-27.05-incompatibilities}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `perlPackages.buildPerlPackage` and `perlPackages.buildPerlModule` now enable `strictDeps` and `__structuredAttrs` by default.
