## Backward Incompatibilities {#sec-nixpkgs-release-27.05-incompatibilities}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- In `buildGoModule`, setting `CGO_ENABLED = 0` no longer necessarily implies that the output binary will be
  statically linked and loaded. Making this change allows us to apply further security hardening by default.
  If static outputs are necessary, use `pkgsStatic` instead, which will disable the incompatible hardening.
