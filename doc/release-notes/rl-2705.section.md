## Backward Incompatibilities {#sec-nixpkgs-release-27.05-incompatibilities}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `dyalog` has been updated from 20.0 to 21.0. See the [upstream release notes](https://dyalog.com/dyalog/dyalog-versions/210.htm).
  - `bin/dyalog` now starts Dyalog's `mapl` launcher, like `/usr/bin/dyalog` in the upstream `.deb`, instead of the interpreter directly.
    It creates and reads the user configuration in `~/.dyalog`, keeps a session log there, reads the serial number from `~/.dyalog/serial`, lets `⎕PW` follow the terminal width and handles the `-rt`, `-bg` and `-kbd` options.
    `dyalogscript` still starts the interpreter directly.
  - With `dotnetSupport`, the .NET bridge now uses the .NET 10 runtime, as Dyalog 21.0 requires.
