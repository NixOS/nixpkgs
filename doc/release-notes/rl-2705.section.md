- `comodoro` 3.0.0 brings breaking changes.
  It drops the configuration wizard, renames the per-second hook `on-<cycle>-running` to `on-<cycle>-tick`, and changes the JSON-RPC wire, so a running server must be restarted after upgrading.
  See the [release notes](https://github.com/pimalaya/comodoro/releases/tag/v3.0.0) and the [migration guide](https://github.com/pimalaya/comodoro/blob/v3.0.0/MIGRATION.md).
