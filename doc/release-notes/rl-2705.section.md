## Other Notable Changes {#sec-nixpkgs-release-27.05-notable-changes}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- Packages can be marked as patent encumbered, with
  [`meta.needsPatentGrant`](#var-meta-needsPatentGrant) or with a license that
  has `needsPatentGrant = true`, such as `lib.licenses.fraunhofer-fdk`.
  Set `config.allowPatentEncumbered = false` to refuse these packages. See
  [installing patent-encumbered packages](#sec-allow-patent-encumbered).
